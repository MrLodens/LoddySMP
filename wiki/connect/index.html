How to connect

How to connect succesfully to LoddySMP on Java Edition and Bedrock Edition

Java Edition

  • Launch Minecraft
  • Press Multiplayer
  • Click on Add Server
  • Enter the following server information:
    • Server Name: LoddySMP
    • Server Address: loddysmp.net
  • Press Done
  • Press Join Server

Bedrock Edition

  • Launch Minecraft
  • Press Play
  • Go to Servers
  • Press Add Server
  • Enter the following server information
    • Server Name: LoddySMP
    • Server Address: loddysmp.net
    • Port: 12000
  • Press Add Server and play

Bedrock Edition on Console

Joining LoddySMP on console is a bit trickier.

  • Install the app called BedrockTogether on your phone
  • Follow the Bedrock steps above
