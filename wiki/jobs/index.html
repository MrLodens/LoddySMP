Jobs

Earn money by doing two of your favourite acitivies.

How it works

  1. Type /jobs browse and pick 2 jobs.
  2. Start doing the activities and start earning money.

Commands

Command Description
/jobs browse Display all available jobs
/jobs join [job] Join a job
/jobs info [job] Display activity payments
/jobs Display all jobs commands
/jobs leave [job] Leave a job
/jobs leaveall Leave all joined jobs
/jobs stats Display your job levels
